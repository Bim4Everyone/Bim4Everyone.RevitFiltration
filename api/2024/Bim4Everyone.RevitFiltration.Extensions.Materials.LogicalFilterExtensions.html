BuildMaterialsFilter(ILogicalFilter, Document, MaterialOptions)

Отбирает материалы документа, которые проходят правила фильтра, и создает фильтр элементов по этим материалам. Значения параметров материалов сравниваются напрямую, без создания фильтров Revit.

public static MaterialsFilter BuildMaterialsFilter(this ILogicalFilter filter, Document doc, MaterialOptions opts)

Parameters

filter ILogicalFilter

Правила отбора материалов по значениям их параметров.

doc Document

Документ, в котором отбираются материалы.

opts MaterialOptions

Настройки отбора материалов.

Returns

MaterialsFilter

Фильтр элементов по материалам.

Remarks

Материалы отбираются сразу, за один проход по документу, поэтому созданный MaterialsFilter в документ больше не обращается и не увидит изменений, сделанных после его создания. Фильтру без единого правила удовлетворяет любой элемент.

Exceptions

ArgumentNullException

Любой из аргументов null.

InvalidOperationException

Исключение, если нельзя построить фильтр по материалам.
